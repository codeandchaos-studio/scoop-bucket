# Code & Chaos Scoop Bucket

Official Scoop bucket for applications and developer utilities created by **Code & Chaos Studio**.

## Quick Start

### 1. Add the Code & Chaos Bucket:
```powershell
scoop bucket add codeandchaos https://github.com/codeandchaos-studio/scoop-bucket
```

### 2. Install Applications:

#### D-Deck (Desktop Task HUD & Sprint Timer)
```powershell
scoop install ddeck
```

To update when new releases drop:
```powershell
scoop update ddeck
```
